# 🏛️ Sistema Catedral Lausanne (v51.2.4 Diamond Phoenix)

### Guia Oficial de Operação e Gestão de Dados

Este documento é a fonte única de verdade para a operação tecnológica da Catedral Lausanne. Todo o sistema foi unificado na arquitetura **v51.2.4 Diamond Phoenix** para garantir fluidez total em dispositivos móveis e segurança de dados de elite.

---

## 🚀 1. Acesso ao Sistema

O sistema é inteligente e detecta automaticamente o seu dispositivo.

- **URL de Acesso**: `https://catedral-connect-bf717.web.app/`
- **Visitantes (QR Code)**: Devem acessar a URL acima. O sistema abrirá o **Hub Connect** (v51.2.4) com 4 pilares: Início, Bíblia, Agenda e Membros.

- **Equipe (Obreiros)**: Ao acessar, escolha o seu módulo (Recepção, Kids, Secretaria) e insira a senha do departamento.

---

## 📋 2. Módulos Operacionais

### 🏢 Secretaria Admin (Master)

- **Performance**: Sintonizado com o Motor v51.2.4 Diamond Phoenix. Dashboards instantâneos.
- **Correção Master**: Suporte nativo para a Chave Mestra (Bypass v51.2.4). O Dashboard agora abre sem travamentos, ignorando estados de espera do Firebase quando necessário.
- **Interface**: Blindagem contra abertura acidental de modais no carregamento.

### 🧒 Kids (Berçário e Ministério Infantil)

- **Função**: Gestão de check-in infantil com segurança v51.2.4 Diamond.

### 🤝 Recepção (Acolhimento)

- **Função**: Cadastro de visitantes integrado em tempo real.

### 🏛️ Altar (Liturgia)

- **Sincronização**: Conectado diretamente ao Shell via Síncronia Gold.
- **Inteligência**: Monitoramento dinâmico de decisões e avisos.

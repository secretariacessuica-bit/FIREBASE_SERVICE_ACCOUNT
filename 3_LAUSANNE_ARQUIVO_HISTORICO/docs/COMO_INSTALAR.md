# 📲 Guia de Instalação: Catedral Connect (Android 14)

Siga este passo-a-passo para instalar a versão oficial de segurança v49.2 e eliminar o aviso de "app de risco".

### 1. Limpeza de Segurança (Importante) 🧹
Antes de tudo, **desinstale** qualquer versão do aplicativo que você já tenha no celular. (Segure o dedo sobre o ícone e clique em "Desinstalar").

### 2. Acesso via Chrome 🌐
Abra o navegador **Google Chrome** no seu Android e acesse o link oficial:
👉 `https://catedral-connect-bf717.web.app/mobile.html`

### 3. Instalação Oficial 🚀
1. No canto superior direito do Chrome, clique nos **3 pontinhos** (⋮).
2. Procure a opção **"Instalar Aplicativo"** ou **"Adicionar à tela de início"**.
3. Clique em **Instalar**.

### 4. Por que é Seguro? 🛡️
Diferente dos arquivos APK antigos, este método usa a tecnologia **PWA (Progressive Web App)** do Google. Isso garante que:
- O Android reconheça o app como **Certificado**.
- Todas as proteções de privacidade do Android 14/15 estejam ativas.
- O app se atualize sozinho toda vez que eu fizer uma melhoria aqui.
